Weekly focus

The 30 days are grouped into four phases: foundations, networking and methodology, offensive web and enumeration, and finally defensive monitoring, detections, and threat hunting.

Week 1 · Days 1–7

Foundations and operating systems

Information security basics, learning workflow, Linux, and Windows.

  • Build your note‑taking and problem‑solving system.
  • Get comfortable in Linux and Windows without worrying about syntax.
  • Produce your first command and permissions cheat sheets.
Week 2 · Days 8–14

Networking, AD, and pentest flow

Networking fundamentals, Active Directory basics, and full pentest methodology with Nmap.

  • Understand how systems talk: IP, DNS, routing, services, ports.
  • Learn AD structure and attacker enumeration thinking.
  • Develop repeatable recon and scanning habits with Nmap.
Week 3 · Days 15–21

Web, proxies, and recon

Vulnerability assessment, HTTP, web applications, Burp, and full web recon workflows.

  • See how vulnerabilities relate to real severity and impact.
  • Understand HTTP traffic and how web apps are structured.
  • Practice end‑to‑end web enumeration on a target.
Week 4 · Days 22–30

Ops, SIEM, detections, and hunting

File transfers, JavaScript analysis, SIEM, detection engineering, hunting, and portfolio prep.

  • Learn how attacker behavior shows up in logs.
  • Write and validate basic detection rules and hunt scenarios.
  • Turn your work into interview‑ready portfolio material.

30‑day module and practice plan

Each card is one day. Do the module sections, complete the practice, finish the lab focus, and produce the deliverable. If something takes longer, finish it properly and compress on easier days.

Not started
